Second phone as a button pad

Open /deck on any phone or tablet. It's a Stream Deck–style pad with live lights (blinkers flash, cruise shows the set speed). Tap Edit to change buttons; the layout is saved on the server, so every device shares it.

iPhone: Share → Add to Home Screen to open it full-screen.

Stream Deck / Companion / Touch Portal

Every action below has a URL. Any tool that can send an HTTP request can press it:

Elgato Stream Deck: install the free API Ninja or Web Requests plugin, add a button, paste the URL (GET).

Linux (StreamController): add a Run command action with curl -s URL.

Bitfocus Companion / Touch Portal: "HTTP GET" action with the URL.
